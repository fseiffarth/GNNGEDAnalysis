# Statistical Validation of Decision Findings (real-world molecule datasets)

## Context

The "decision findings" in this project describe how GNN class predictions **flip**
along graph-edit-distance (GED) paths. For the real-world molecule datasets
(MUTAG, Mutagenicity, DHFR, NCI1, NCI109, PTC_FM/FR/MM/MR, ogbg-molhiv) these
findings are produced by `experiments.py` and `experiments_additional.py`. Today
they are **purely descriptive**: each writes per-fold values to `*_fold_counts.csv`
and then `mean/std/min/max` across folds to `*_summary.csv`. There is **no
significance testing, no confidence intervals, and no handling of the nested data
structure** (edit step → path → CV fold → trained model). Treating each step as an
independent observation would massively overstate significance, so claims like
"EDGE DELETE flips decisions more than NODE INSERT" or "GIN flips more than
GraphSAGE" are currently unverified.

This work adds a statistical-validation layer that turns those descriptive numbers
into defensible claims with p-values, multiple-comparison control, effect sizes,
and confidence intervals — respecting the nested structure (the **CV fold is the
unit of replication**).

Scope: validate four finding families — (1) operation-type flip effects,
(2) GNN architecture differences, (3) margin/confidence vs flips, (4) sequence/
position effects. Framework: **two-tier** — fold-level nonparametric tests for
headline claims + a mixed-effects / cluster-robust logistic model (GLMM) as
confirmatory analysis. Dependencies: add `statsmodels` (scipy already present).

## Data & sample sizes

- Most molecule datasets: **10 CV folds** (`val_id` 0–9) per (gnn, strategy, split)
  → n=10 replication units for fold-level tests.
- **ogbg-molhiv: single official split (1 fold)** → fold-level tests are not
  applicable; it falls back to within-fold **cluster bootstrap over paths** and the
  GLMM (clustered on path), which still yields valid inference.
- Inputs already on disk:
  - Per-fold statistics: `results/Experiments/*/...fold_counts.csv` and
    `results/ExperimentsAdditional/*/...fold_counts.csv` (written by the existing
    experiment scripts; columns include `dataset, gnn_algorithm, path_strategy,
    split, val_id, operation_str, ..._count / flip_rate / enrichment_ratio`).
  - Per-step rows for the GLMM: `results/all_results.csv` (30 cols incl.
    `is_flipping, operation_str, class_0/1, predicted_label, val_id, gnn_algorithm,
    dataset, path_strategy, path_idx_int, step_id`).
- The tooling is **dataset-agnostic**: it reads whatever `fold_counts.csv` rows
  exist and filters by `--dataset`. Molecule experiment outputs are (re)generated by
  running the existing pipeline.

## Approach

A new top-level CLI script `statistical_validation.py` plus a shared `utils/stats.py`
helper module. The script does **not** recompute flip aggregations — it consumes the
per-fold `*_fold_counts.csv` files that `experiments.py` / `experiments_additional.py`
already emit (Tier 1) and `all_results.csv` for the GLMM (Tier 2). Output goes to a
new `results/StatisticalValidation/` directory: one tidy results CSV per finding
family plus a `report.md` summary, mirroring the existing `results/Experiments/`
layout and `click`-CLI conventions.

### Tier 1 — Fold-level nonparametric tests (headline claims)

For each (dataset, gnn, strategy, split) cell, take the per-fold values and test:

- **Finding 1 — Operation-type flip effects.** Treatments = operation types,
  blocks = folds. **Friedman test** on per-fold `relative_decision_change_count`
  (from `experiments_flips_per_operation_relative/...fold_counts.csv`). Effect size:
  **Kendall's W**. Post-hoc: pairwise **Wilcoxon signed-rank** (paired by fold) with
  **Holm** correction; report rank-biserial effect size per pair.
- **Finding 2 — GNN architecture differences.** Same fold ids share the same graph
  partition across architectures → repeated-measures: **Friedman across GNNs**
  blocked by fold (per dataset/strategy/split). Post-hoc Wilcoxon + Holm.
- **Finding 3 — Margin vs flips.** From
  `experiments_margin_to_flip_analysis/margin_to_flip_calibration_fold.csv`: test the
  ordered margin bins for a **monotone decreasing** flip rate using a per-fold
  **Page's trend test**. Also the direct claim from `..._distribution_summary.csv`:
  **Wilcoxon signed-rank** of `mean_margin_flipping` vs `mean_margin_non_flipping`
  paired by fold; effect = paired mean difference + CI.
- **Finding 4 — Sequence/position effects.**
  - `flip_position_sensitivity`: **Friedman** across early/mid/late position bins
    (blocked by fold) on `flip_rate`; post-hoc Wilcoxon + Holm.
  - `operation_transition_instability`: per bigram/trigram, **one-sample Wilcoxon
    signed-rank** on per-fold `log(enrichment_ratio)` vs 0, filtered to sequences
    meeting the existing `min_transition_count`.
  - `flip_streaks_and_recovery`: compare per-fold `mean_recovery_rate` across GNNs/
    strategies with Friedman where a comparison is meaningful.

Cross-cutting Tier-1 mechanics (in `utils/stats.py`):
- **Multiple comparisons:** collect every p-value within a finding family and apply
  **Benjamini-Hochberg FDR**, reporting both raw and adjusted p.
- **Effect sizes + CIs:** Kendall's W (Friedman), rank-biserial (Wilcoxon), and
  **cluster bootstrap** CIs for every reported point estimate — resample folds with
  replacement (≥2000 reps); for single-split data resample paths instead.
- Guard rails: cells with too few folds (n<5) report estimate + bootstrap CI but no
  p-value; never emit a Friedman p on <3 groups.

### Tier 2 — Mixed-effects / cluster-robust logistic regression (confirmatory)

Per dataset, on the per-step rows from `all_results.csv` (filtered to path steps,
optionally split), model the binary `is_flipping`:

```
is_flipping ~ C(operation_str)   with random intercepts for fold (val_id) and path
```

- Primary: **`statsmodels` GEE** with `family=Binomial()`, grouped on a composite
  **path id** (gnn+strategy+val_id+path_idx_int), `cov_struct=Independence()` →
  population-averaged operation odds-ratios with **cluster-robust SEs**. Scales to
  the multi-million-row CSV and works on single-split ogbg-molhiv.
- Alternative for smaller datasets: **`BinomialBayesMixedGLM`** with random
  intercepts for fold and path.
- Output per dataset/gnn: operation odds-ratios, 95% CIs, FDR-adjusted p-values,
  and a note on whether the Tier-1 ordering of operation effects holds.

  `page_trend_test`, `kendalls_w`, `rank_biserial`, `cluster_bootstrap_ci`, `bh_fdr`.

- `results/StatisticalValidation/` — `operation_effects_tests.csv`,

- `requirements.txt` — add `scipy`, `statsmodels`.
- `DOCUMENTATION.md` — add a "Statistical validation" section.
